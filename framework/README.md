# ezMU Framework (layer L4)

Genre modules for classic MMORPGs: terrain, navigation, camera, controller, character,
items, effects, replication, session, social and game UI.

The Framework provides **mechanisms**; games define **policy**. It is built only on the public
API of the ezMU Engine, and each module is optional and independent.

See [ADR 0011](../docs/adr/0011-layered-architecture-engine-and-framework.md). No modules yet.
